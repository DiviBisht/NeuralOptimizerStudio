# Deep Learning Optimizer Visualizer

An interactive visualization tool for understanding and comparing optimization algorithms used in deep learning. This project implements popular optimizers such as Stochastic Gradient Descent (SGD), Momentum, Adam, and others to demonstrate their behaviour on different loss surfaces.

Built using Python and Streamlit, the application allows users to experiment with optimizer parameters and observe their trajectories through graphical visualizations. Matplotlib and Plotly are used to generate interactive loss surfaces and convergence plots.

## Features

* Interactive visualization of deep learning optimization algorithms
* Implementation of SGD, Momentum, Adam, and other optimizers
* Real-time visualization of optimizer trajectories on loss surfaces
* Comparison of convergence behaviour and optimization performance
* Adjustable hyperparameters through an interactive Streamlit interface
* Educational tool for students, researchers, and machine learning enthusiasts

## Technologies Used

* Python
* Streamlit
* Matplotlib
* Plotly
* NumPy
* Deep Learning Optimization Algorithms

## Objective

The primary goal of this project is to provide a visual and intuitive understanding of optimization techniques used in deep learning, helping users analyse how different optimizers navigate loss landscapes and converge towards optimal solutions.
